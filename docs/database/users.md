# `users`

## Purpose

Stores application user accounts and profile data. A user is the parent record for authentication-related data, contacts, conversations, messages, calls, invites, and pins.

## Features

- UUID primary key generated by Prisma.
- Unique email, username, and optional phone number.
- Profile fields for name, about text, and avatar.
- Soft-delete support through `deleted_at`.
- Account state represented by `UserStatus`: `active`, `inactive`, or `banned`.

## Key Fields

- `id`: Primary key.
- `email`, `username`: Required unique identity fields.
- `phone`: Optional unique phone number.
- `status`: Account status.
- `created_at`, `updated_at`, `deleted_at`: Lifecycle timestamps.

## Relations

- One-to-one with `user_settings`.
- One-to-many with `user_devices`, `user_sessions`, `contacts`, `blocked_users`, `conversations`, `groups`, `conversation_members`, `messages`, `group_invites`, `pinned_messages`, `message_reactions`, `message_receipts`, `calls`, and `call_participants`.
- One-to-many with `private_conversations` through the `user_a` and `user_b` roles.
- Self-related message deletion records through `messages.deleted_by`.
